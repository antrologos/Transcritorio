# Como usar o Transcritório

O caminho básico é este:

**Adicionar mídia** → **Transcrever** → abrir a entrevista com duplo clique →
revisar o texto → **Salvar transcrição** → **Exportar…**

O resto desta página explica cada passo em uma ou duas frases. Ela vem dentro do
programa e funciona sem internet. O manual completo, com imagens, está em
[antrologos.github.io/Transcritorio](https://antrologos.github.io/Transcritorio/pt/).

## 1. Criar um projeto

Um projeto é **uma pasta única** com todo o trabalho de uma pesquisa:
Projeto → Novo projeto…

Suas gravações **não são copiadas nem alteradas**. O projeto apenas aponta para
onde elas estão. Se você mover ou renomear os áudios depois, o projeto pede que
você os localize de novo.

## 2. Adicionar as gravações

Arraste os arquivos para a janela, ou use
Projeto → Adicionar mídia → Adicionar arquivos…

Aceita MP3, M4A, WAV, FLAC, MP4 e MOV. Vídeo funciona: o programa usa o áudio e
mostra a imagem enquanto você revisa.

## 3. Transcrever

Marque as gravações na lista e use Entrevista → Transcrever selecionados.
Sem nenhuma marcada, o botão **Transcrever** faz todas as que ainda não têm texto.

A caixa **Separar falantes** (Entrevista → Separar falantes) decide se o programa
tenta descobrir quem fala em cada trecho. Deixe ligada para entrevistas; desligue
para gravações de uma pessoa só, que ficam mais rápidas assim.

Tudo acontece **no seu computador**. Nenhum áudio é enviado para a internet.

## 4. Dizer quem é cada voz

Ao abrir uma transcrição nova, o programa toca uma amostra de cada voz e pergunta
de quem é. Se você adiar, a pergunta volta em
Entrevista → Dar nome às vozes…

Os nomes que você der valem para os documentos exportados, e o programa passa a
reconhecer as vozes que se repetem entre entrevistas do mesmo projeto.

## 5. Revisar — é aqui que está o trabalho

Abra a entrevista com duplo clique. A tela tem três partes: a gravação com a onda
sonora em cima, a lista de blocos no meio e o texto do bloco aberto embaixo.

O ciclo é sempre o mesmo: **ouvir, corrigir, seguir**. Ele foi desenhado para
acontecer sem tirar a mão do teclado:

- **F4** toca e pausa · **F3** repete o bloco desde o começo
- **Alt+←** e **Alt+→** voltam e avançam 5 segundos; com **Shift**, 2 segundos
- **Alt+↓** e **Alt+↑** vão ao bloco seguinte e ao anterior, levando o áudio junto
- **Alt+Shift+↓** pula direto para o próximo bloco marcado para conferir
- **Alt+D** divide o bloco no ponto do cursor
- **Alt+J** junta com o bloco seguinte; **Alt+Shift+J**, com o anterior
- **Alt+P** passa o fim do bloco para o bloco seguinte, com o falante de lá —
  é o conserto de quando a separação automática errou a fronteira.
  **Alt+Shift+P** faz o contrário
- **Alt+E** abre a lista de falantes do bloco
- **Ctrl+Z** desfaz. Sempre.

A lista inteira, com tudo o que o programa faz, está em
Ajuda → Atalhos e comandos, ou na tecla **F1**.

Trocar de bloco já salva o que você escreveu. **Ctrl+S** salva a transcrição toda.

## 6. Analisar

Com as transcrições prontas:

- Analisar → Buscar palavras… procura expressões exatas em todas as entrevistas.
- Analisar → ✨ Buscar por sentido e perguntar… acha trechos pelo assunto, mesmo
  quando as palavras são outras.
- Analisar → ✨ Temas das entrevistas… agrupa os trechos por tema e deixa aplicar
  códigos, que saem depois para o QualiLab ou para uma planilha.

Tudo isso também roda no seu computador.

## 7. Exportar

Projeto → Exportar… gera os documentos finais: **.docx** e **.md** para leitura,
**.srt** e **.vtt** para legendas, **.csv** para planilha.

Eles ficam na pasta **Resultados**, dentro do projeto — a aba **Documentos** tem
um botão que abre essa pasta.

## Se algo der errado

- A barra de baixo sempre diz o que está acontecendo e o que acabou de acontecer.
- Um comando cinza explica no seu balão por que está cinza.
- Ajuda → Reparar instalação… reconstrói a parte técnica sem tocar nos seus
  projetos, áudios, transcrições ou modelos.
